# Prioritizing Heat Mitigation in Dasmariñas, Cavite

ML Research Lab team project — using multi-temporal Landsat satellite data
and machine learning to identify which barangays in Dasmariñas, Cavite are
most in need of heat mitigation interventions.

## Team
- Justine Paras
- Elisha Yang
- Ikpi

## Structure
- `notebooks/` — Colab notebook(s) for the full pipeline (data extraction, modeling)
- `data/` — geographic boundary files and source data
- `outputs/` — generated results (CSVs, per-barangay statistics)
- `docs/` — project plan and written report materials
- `dashboard/` — interactive prioritization dashboard prototype

## Data sources
- Landsat 8/9 Collection 2 Level-2 (Google Earth Engine)
- Barangay boundaries: PSA/NAMRIA 2023, via `faeldon/philippines-json-maps`
